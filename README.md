# Форма — тренування і харчування

Вебзастосунок (PWA) для iPhone: облік їжі й калорій, тренування з прогресією, відновлення за даними Apple Watch. Працює без інтернету після першого відкриття.

Відкрити: https://anderoii.github.io/forma/

Щоб встановити: Safari → «Поділитися» → «На екран „Додому“».

Сканер штрихкодів — [html5-qrcode](https://github.com/mebjas/html5-qrcode) (Apache 2.0, див. `scan-LICENSE.txt`). Дані товарів — Open Food Facts (ODbL).

## Автоперенесення даних Apple Watch

Сайт не має доступу до «Здоров'я», тому дані надсилає команда iPhone на маленький безплатний сервер (Cloudflare Worker, код — `worker/health-sync.js`), а «Форма» сама забирає їх щоразу при відкритті. Покрокова інструкція — у застосунку: «Профіль» → «Apple Watch» → «Налаштувати автоперенесення».
